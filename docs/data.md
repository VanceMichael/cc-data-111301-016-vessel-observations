# 来源资料约定

来源是 NMEA AIVDM 句子，星号后为 XOR 校验。外层 `connections.json` 给出岸站和连接身份，原始 NMEA 顺序号并非全局唯一。station-a 与 station-b 为两路独立来源；相同句子在另一岸站出现不自动代表同一次接收。静态字段和位置字段分别来自不同消息类型。

## 分片身份

一个分片组由下列作用域共同界定，任一不同都不进入同一组：

- 岸站与连接（`station`、`connection`），以及该连接当前的代次（`generation`）；
- 频道（`channel`）与 formatter；
- 顺序号（`sequence`）与总片数（`total`）。

总片数为 1 的句子自成一条观测。多片消息只有收齐 1..N 才组装；`fill` 只取末片的值，其余片段的非零填充位会被拒绝。

## 顺序与异常处置

| 情形 | 处置 |
| --- | --- |
| 顺序号相同但来源不同 | 分属两个组，绝不拼接 |
| 顺序号不为空、乱序到达 | 收齐后正常组装，记录 `reordered: true` 与每片到达序号 |
| 缺片 | 收齐前保持挂起；输入结束、超过期限或被上限挤出时成为 `unresolved`，给出 `missing_parts` 与可机器汇总的 `detail` |
| 同一片重复到达（内容相同） | 记为 `duplicates`，不增加接收计数 |
| 同一位置出现不同内容 | 原组转为 `unresolved`（`detail: conflicting_part`），冲突片段另起一组继续等待，两者不互相拼接 |
| 顺序号为空的片段 | 只有从第 1 片起连续到达才组装；乱序、缺片或同位置冲突一律 `unresolved`，不猜测配对 |
| 岸站重连 | 代次加一，旧代次半包立即转 `unresolved`，不会串进新连接 |
| 半包长期未齐 | 以同一来源连接后续到达的片段数计过期（默认 64），移入 `unresolved`；另有挂起组数上限 |

重复回放（同一来源连接再次出现完全相同的句子）只进入 `duplicates`，不新增观测，也不改变各来源的观测计数。

## 支持的报文

| 类型 | 内容 | 观测字段 |
| --- | --- | --- |
| 1 / 2 / 3 | A 类位置报告 | 经纬度、SOG、COG、艏向、导航状态、时间戳 |
| 18 | B 类位置报告 | 同上（B 类标志） |
| 5 | 完整静态与航次资料 | 船名、呼号、IMO、类型、尺寸、目的地、ETA、吃水 |
| 24A | 静态资料 A 部 | 船名 |
| 24B | 静态资料 B 部 | 呼号、类型、厂商编号、尺寸 |

其他类型保留原文与原因，进入 `unprocessed`，不会创建空船舶。

## 查询视图

`query` 按 MMSI 输出：

- `static.fields`：每个字段一项，带 `value` 与 `observation_id`（及来源连接、代次、频道、顺序号、分片）；不同字段依据各自最近一次明确给出该值的观测，不会因为另一字段更新而改写依据。
- `static.complete` / `missing_fields` / `parts_received`：静态资料是否齐全，缺哪些必备字段（船名、呼号、尺寸），收到过哪些静态分部。
- `position`：最近一次位置报告的原样结果。经纬度为 AIS 不可用哨兵值时 `available: false`，不会用上次位置填充本次测量。
- `last_available_position`：最近一次经纬度可用的报告，单独标出，便于区分“本次不可用”和“可用位置来源”。
- `observations`：该船每条观测的摘要，可按 `observation_id` 回溯到上方字段依据。
- `source_observations`：按岸站/连接/代次统计的观测条数。

`receive` 另外输出 `unresolved`（仍未组装的组及原因）、`unprocessed`（不支持或无法解码的原文）、`duplicates`（重复回放）与 `observation_counts`（各来源的观测数及接收片段数）。
